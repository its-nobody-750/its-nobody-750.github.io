# Micaiah Raj R - Modern Portfolio

Ultra-modern portfolio with glassmorphism, vibrant gradients, and smooth animations.

## 🎨 Design Features

- **Dark Mode** - Sleek dark background with vibrant accents
- **Glassmorphism** - Frosted glass effect on cards
- **Animated Gradients** - Purple/pink/cyan rotating background
- **Floating Orbs** - Blur orbs with smooth float animation
- **Smooth Animations** - Fade-in on scroll, hover effects
- **Pineapple Boss Logo** - Your custom image as logo/icon
- **Responsive** - Perfect on all devices

## 🎯 Color Palette

- Purple: #a855f7
- Pink: #ec4899
- Blue: #3b82f6
- Cyan: #06b6d4
- Dark BG: #0a0a0f

## 🚀 Quick Deploy

1. Upload to GitHub: `yourusername.github.io`
2. Enable Pages: Settings → Pages → main branch
3. Done! Live at `https://yourusername.github.io`

## 📝 Customization

**Change Colors** (styles.css):
```css
--accent-purple: #a855f7;  /* Main accent */
--accent-pink: #ec4899;    /* Secondary */
```

**Update Logo**:
- Replace `logo.jpg` with your image
- Keep it square (1:1 ratio)

## 📁 Files

- index.html - Main page
- styles.css - Styling
- script.js - Interactions
- logo.jpg - Your pineapple logo

## 🌐 Custom Domain

Create `CNAME` file:
```
yourdomain.com
```
